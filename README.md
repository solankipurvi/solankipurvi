## Featured project

### [BlindParse](https://github.com/solankipurvi/BlindParse)

A privacy-focused document extraction app. PDFs and images are parsed in the browser, detected PII can be reviewed and redacted, and scrubbed text is sent to a schema-based extraction API.

## Open source

I’m happy to collaborate on full-stack products, APIs, cloud systems, and privacy-aware tools. If you’re contributing to BlindParse, start with the project README, keep pull requests focused, and use synthetic documents in examples and issue reports.
