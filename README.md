## Featured project

### [BlindParse](https://github.com/solankipurvi/BlindParse)

A privacy-focused document extraction app. It parses PDFs and images in the browser, lets people review PII redactions, and sends scrubbed text to a schema-based extraction API.

## Open-source contributions

I welcome collaboration on full-stack applications, APIs, cloud systems, and privacy-aware tools. To contribute to BlindParse:

1. Fork the repository and create a focused branch.
2. Follow the setup instructions in its README.
3. Open a pull request with a clear summary and steps to review or reproduce the change.
4. Use synthetic documents and data in examples or issue reports; never include private personal information.
